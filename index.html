🏛️ The 4 Pillars of Object-Oriented Programming in "Training to War"
1. Encapsulation (Data Bundling)

class Soldier bundles self.health, self.stamina, and self.rank with guarded methods (issue_rations(), apply_medkit()), while BaseEconomy protects War Funds.

2. Inheritance (15 Subclasses)

All 15 units (InfantryRifleman, ReconSniper, FieldMedic, TierOneCommando, etc.) inherit core attributes and methods from base class Soldier.

3. Polymorphism (Specialized Behavior)

Each subclass customizes combat behavior—e.g., Combat Medic regenerates HP faster, Sniper gains bonus Drill XP, and Heavy Gunner mitigates injury damage.

4. Abstraction (Clean Interfaces)

High-level controllers like BarracksDispatcher, MissionDispatchQueue, and CommandStack hide 2D matrix math and pointer manipulation behind simple method calls.
